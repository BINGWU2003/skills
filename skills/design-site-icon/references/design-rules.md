## 参考研究

优先研究与目标网站在内容、受众或视觉气质上接近的产品。记录每个参考的 URL、图标使用场景以及一条值得借鉴的抽象原则。

把观察转换为设计参数：

| 观察 | 可用参数 |
| --- | --- |
| 页面克制、留白多 | 减少路径数量，保留宽阔负空间 |
| 技术或开发者定位 | 采用模块、容器、节点、命令等隐喻 |
| 深色界面 | 使用高对比浅色描边，避免细灰线 |
| 图标带手写感 | 使用圆角端点和不完全对称的节奏 |
| 动效安静 | 延长循环，设置足够长的停留阶段 |

不要用“风格相似”代替具体观察。

## 概念与轮廓

先写出隐喻，再画路径。一个可靠概念同时满足：

1. 与网站主题有关；
2. 一眼形成稳定轮廓；
3. 缩小后仍能区分；
4. 动画能解释其含义，而不是附加装饰。

在落图前列出可能的错误联想，例如蛇、无限符号、链条、纸箱、云朵或已有品牌标志。通过改变外轮廓而不是增加细节来消除错误联想。

## 候选差异

默认三套候选分别采用不同类别的隐喻，例如：

- 容器类：软件包、盒子、胶囊；
- 系统类：模块网格、节点网络、层级；
- 行为类：命令、装配、连接、展开。

三个候选应该能仅凭剪影区分。以下变化不足以形成新候选：

- 旋转或镜像同一路径；
- 只改变圆角或描边粗细；
- 只更换内部符号；
- 只改变动画方向或速度。

## 小尺寸设计

- 使用正方形 viewBox，并给图形四周保留一致安全区。
- 24–32 px 的页头 Logo 通常只保留 3–5 个主要结构。
- 16 px favicon 使用更少路径、更粗描边和更大的内部空隙。
- 不依赖低对比色、细小断点或只有动画过程中才出现的信息。
- 在像素尺寸预览，而不是只放大查看矢量路径。

## 反馈迭代

把主观反馈转换为结构约束：

| 用户反馈 | 下一轮动作 |
| --- | --- |
| “像蛇” | 去掉连续蜿蜒轮廓，改为封闭或分段几何 |
| “太普通” | 更换隐喻或引入一个可识别的结构特征 |
| “不像这个网站” | 重新核对内容定位、字体、布局与参考站点 |
| “动画可以，图形不好看” | 保留动效节奏，完全重做静态轮廓 |
| “太复杂” | 减少主路径和交叉点，扩大负空间 |

每一轮先说明哪些约束发生变化，再展示新方案。

## 原创性边界

允许借鉴通用视觉语法，如单色描边、圆角端点、路径绘制和缓慢呼吸。禁止复制参考 Logo 的独特轮廓、路径坐标、字母组合、专有配色组合或可识别动画序列。

如果候选与知名品牌产生明显相似性，主动更换轮廓。
