# 网站图标设计

把网站图标视为一个需要研究、比较和验证的微型品牌系统，而不是一次性的 SVG 绘制任务。默认输出原创矢量图形；不要临摹参考网站的具体轮廓。

## 工作流

### 1. 建立上下文

1. 检查用户给出的 URL、本地项目、现有 Logo、站点截图和品牌文字。
2. 从项目中确认页头背景、主题模式、实际显示尺寸、资源路径、框架和构建命令。
3. 优先从现有信息推断；只有会实质改变方向且无法发现时才询问用户。
4. 先确认当前阶段：研究、出候选、迭代、定稿或接入。未选定方案时不要直接替换生产资源。

### 2. 研究并提炼设计语言

用户给出参考站点时，检查其实际图标文件和页面使用方式。用户要求寻找参考时，选择 3–5 个定位或视觉气质接近的网站。

只提炼可复用原则，例如线条粗细、留白、几何秩序、动效节奏和明暗对比；不要复制独特轮廓、字母组合或路径数据。设计候选前阅读 [references/design-rules.md](references/design-rules.md)。

用简短设计摘要记录：

- 网站表达什么；
- 图标需要传达什么；
- 目标背景与关键尺寸；
- 应避免的错误联想；
- 参考设计中可借鉴的抽象原则。

### 3. 生成三套候选

默认生成 3 套，而不是一个。每套必须使用不同的语义隐喻和明显不同的外轮廓；只改变内部线条、旋转角度或动画延迟不算不同方案。

每套至少提供：

- 一个可独立打开的动态 SVG；
- SVG 内的 `<title>` 和 `<desc>`；
- 静止时也完整成立的图形；
- `prefers-reduced-motion` 静态降级；
- 一句话说明隐喻和动效含义。

优先使用 `viewBox="0 0 512 512"`，避免外部字体、脚本、图片和网络资源。需要描边动画时可从 [assets/animated-logo-template.svg](assets/animated-logo-template.svg) 改造；不得把模板造型直接当成候选。

使用预览脚本生成统一对比页面：

```bash
python <skill-dir>/scripts/build_preview.py --input <candidate-dir> --output <candidate-dir>/preview.html --title "图标候选" --dark-background "#050505" --light-background "#fafafa"
```

把预览背景设置为目标网站的实际颜色；不要为了预览好看而临时修改候选图标颜色。

向用户展示三套候选并等待选择。收到“太像某物”“不够好看”等反馈时，把它转换为可操作约束，下一轮更换语义隐喻和外轮廓，不要只做微调。

### 4. 制作生产资源

用户选定方案后再制作：

- `logo.svg`：保留合适的内部 CSS 动画；确保作为 `<img>` 外链时仍能工作。
- `favicon.svg`：静态、路径更少、线条更粗，按需通过 `prefers-color-scheme` 适配主题。
- 可选静态 Logo：仅在分享卡片、邮件或目标平台不支持 SVG 动画时生成。

制作动效前阅读 [references/svg-motion.md](references/svg-motion.md)。favicon 可从 [assets/favicon-template.svg](assets/favicon-template.svg) 改造，但必须替换模板路径。

不要假设外链 SVG 中的 `currentColor` 会继承页面文字颜色。根据目标背景写入明确颜色，或提供独立的明暗资源。

### 5. 验证

先运行 SVG 检查：

```bash
python <skill-dir>/scripts/validate_svg.py <logo.svg> <favicon.svg>
```

再完成以下检查：

1. 在 16、24、28、32、48 和 128 px 下检查辨识度；favicon 重点检查 16 和 32 px。
2. 检查浅色、深色背景和浏览器标签页。
3. 检查首帧、完整循环、循环衔接以及 reduced-motion。
4. 检查 Logo 在页面上的基线、留白和点击区域。
5. 运行项目已有的格式、类型、测试和构建命令。
6. 能使用浏览器时完成页面截图和控制台检查；无法执行视觉验收时明确说明限制，不能声称已经完成。

### 6. 接入与交付

只有用户要求接入或已经确认候选时才修改站点。遵循项目现有的资源路径和组件写法，保留无障碍名称；装饰性 `<img>` 使用空 `alt`。

交付时列出：

- 采用的概念及设计理由；
- 动态 Logo、favicon 和预览文件；
- 实际运行的验证命令与结果；
- 尚未完成的人工视觉检查；
- 是否保留候选文件、是否提交版本控制。
