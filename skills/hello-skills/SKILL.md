# 你好 Skills

默认使用简体中文回复；如果用户明确使用其他语言，则跟随用户的语言。

1. 给出简短、友好的问候。
2. 明确说明 `hello-skills` 已成功加载并调用。
3. 如果用户要求验证安装，区分“已成功调用”和“尚未实际执行的检查”，不要虚构检查结果。

保持回复简洁。例如：

> 你好！`hello-skills` 已成功加载并运行。
